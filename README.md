# Measuring the Real Value of Weather in Flight Delay Prediction before Departure

Source code for the paper. The study quantifies how much of the predictive value of weather survives when a pre-departure delay model may only use information available at issuance time, comparing an *oracle* setting (realized weather at the scheduled times) with *deployable* settings issued H ∈ {0, 2, 6} hours before departure.

## Requirements
Python 3.10+ and the packages in `requirements.txt`:
```
pip install -r requirements.txt
```
Full-data runs are memory-intensive. XGBoost uses a GPU by default (`XGB_DEVICE` in `07_model_comparison.ipynb`; set it to `'cpu'` otherwise).

## Data
Data are not included in this repository.

| Source | Location |
|---|---|
| BTS On-Time Performance, January 2018 – July 2022 ("Flight Status Prediction" dataset on Kaggle, files `Combined_Flights_<year>.parquet`) | `data/raw/bts/` |
| NOAA Local Climatological Data (downloaded by notebook 01) | `data/raw/noaa_lcd/` |

All paths are resolved relative to the project root (the folder containing this `README.md`), so the notebooks can be run from any working directory inside the project.

## Pipeline
Run the notebooks in this order:

| Step | Notebook | Output | Paper |
|---|---|---|---|
| 1 | `01_download_noaa_lcd.ipynb` | `data/raw/noaa_lcd/` | Sect. 4.1 |
| 2 | `02_weather_processing.ipynb` | `data/interim/weather_parquet/`, `data/processed/weather_hourly_utc.parquet` | Sect. 3.2, Table 3 |
| 3 | `03_flights_information_settings.ipynb` | `data/processed/flights_clean.parquet`, `wx_{oracle,H0,H2,H6}.parquet` | Sect. 3.1–3.2, 4.2 |
| 4 | `04_eda_paper_statistics.ipynb` | `figures/eda_*.pdf`, `results/eda_stats.json` | Sect. 4, Fig. 3, Table 4 |
| 5 | `05_modeling_horizon.ipynb` | `results/results_horizon*.csv`, `figures/fig_horizon.pdf` | Sect. 5.1–5.2, Tables 5–6, Fig. 4 |
| 6 | `06_propagation.ipynb` | `results/results_propagation*.csv` | Sect. 5.3, Tables 7–8 |
| 7 | `07_model_comparison.ipynb` | `results/results_model_comparison.csv` | Sect. 5.4, Table 9 |
| 8 | `08_shap_figures.ipynb` | `figures/fig_shap_H2_*.pdf` | Sect. 5.5, Fig. 5 |

Steps 4–8 depend only on the outputs of steps 2–3. Set `SAMPLE = 0.1` in the configuration cell of steps 5–7 for a quick test run. Figs. 1–2 of the paper are diagrams and are not generated by the code.

### Exploratory analysis (`EDA/`)
Run after step 3.

| Notebook | Content |
|---|---|
| `1. Business Understanding and Analytic Approach.ipynb` | Business problem, research questions, analytic approach, data requirements |
