# Measuring_the_Real_Value_of_Weather_in_Flight_Delay_Prediction_before_Departure
Code for "Measuring the Real Value of Weather in Flight Delay Prediction before Departure": audited BTS-NOAA pipeline (9.98M US flights, 137 airports, 2018-2022) comparing oracle vs deployable weather at 0/2/6 h horizons with LightGBM/XGBoost, Shapley attribution and block bootstrap.
